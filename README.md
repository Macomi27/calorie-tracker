# CaloTrack - Vanilla Calorie & Macro Tracker

A responsive, client-side daily calorie and macronutrient tracking web application built strictly with **pure vanilla HTML5, CSS3, and JavaScript**.

No frameworks, no libraries, no Tailwind, and **no CSS variables**. All data persists locally in the web browser using `localStorage`.

---

## ✨ Features

- **Daily Calorie Budget & Interactive Gauge**: Dynamic circular SVG progress ring tracking remaining calories, consumed total, and daily budget with status alerts.
- **Macronutrient Tracking**: Real-time progress bars for Protein, Carbohydrates, and Fats with proportional calorie distribution ratios.
- **Meal Organization**: Group meals into Breakfast, Lunch, Dinner, and Snacks & Drinks with subtotal calories and per-item macro breakdowns.
- **Date Navigation & Calendar**: Switch days with `< Prev`, `Today`, `Next >` or select any past/future date via native date picker.
- **7-Day Activity Chart**: Pure HTML/CSS column chart visualizing weekly caloric intake vs. daily target.
- **Quick Food Presets**: One-click logging for 12 common whole foods (oatmeal, eggs, chicken breast, salmon, avocado, Greek yogurt, etc.).
- **TDEE & Macro Calculator**: Built-in Mifflin-St Jeor formula calculating BMR, daily energy expenditure, and suggested macro splits based on fitness goals.
- **Data Backup & Restore**: Export and import full history as JSON backup files, or reset data anytime.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/Macomi27/calorie-tracker.git

# Open index.html directly in your browser
```

No build step, package manager, or backend server required.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup, accessible modal dialogs, inline SVGs.
- **CSS3**: Pure custom CSS, flexbox/grid layouts, responsive design, dark slate theme.
- **JavaScript (ES6+)**: Pure vanilla DOM manipulation, date management, state handling, and `localStorage` persistence.
